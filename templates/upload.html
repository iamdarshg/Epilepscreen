What the upload does

  • Validation Extension, size and empty-file checks run before anything touches the database.
  • Hashing hashlib.sha256 over the bytes gives a 15-hex-digit key, so a second copy of the same file is rejected by the primary key.
  • Metadata cv2.VideoCapture reads duration and dimensions, which drive the automatic category.
  • Storage The file is compressed with lzma and kept as a blob in the epilepsy table. Streaming decompresses on the fly.
  • Screening The detector writes rows into hazard_event and one verdict into analysis.

A clean report means the five detectors found nothing above their thresholds at the analysis frame rate. It is not a guarantee: every report page lists what the method can miss.

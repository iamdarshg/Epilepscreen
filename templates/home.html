What happens to a file

Three steps, all of them on this machine. No upload leaves it.

01

Store

The file is hashed with hashlib.sha256, compressed with lzma and kept in the database. The same bytes can never be stored twice, because the hash is the primary key.

02

Screen

cv2.VideoCapture decodes about fifteen frames a second. NumPy turns each frame into a luminance map, then flash, red-flash, colour-delta, stripe and pattern-movement scores are compared against thresholds.

03

Play

Flagged runs become rows in hazard_event with a start and end time. The player fetches those times and dims the video while playback is inside them.
